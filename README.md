# VEX V5 Robotics – Push Back (2025–2026)

**Team 9181J | Seaquam Robotics**

Competition robot software developed in **C++** for the 2025–2026 VEX V5 Push Back season, featuring autonomous navigation, PID motion control, odometry, and real-time driver control.

## Features

- **Autonomous Navigation:** Developed coordinate-based movement routines using odometry for position tracking and PID controllers for precise movement and turning. Tuned control parameters to improve autonomous consistency and repeatability.
- **Driver Control:** Implemented real-time drivetrain control and controller mappings for coordinated operation of the robot's drivetrain and multi-stage intake system, enabling simultaneous movement and scoring actions.
- **Motion Control:** Applied feedback-based PID control to minimize movement error and improve drivetrain accuracy during autonomous routines.
- **Hardware Integration:** Configured and integrated VEX V5 motors, encoders, and sensors to support drivetrain movement, intake operation, and robot localization.
